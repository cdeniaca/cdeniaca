## 👩‍💻 Sobre mí

Soy **Data Analyst / Business Process Analyst** y trabajo transformando datos operativos en información útil para tomar decisiones, automatizar procesos y construir soluciones prácticas.

Mi trabajo combina **Business Intelligence, análisis de datos y automatización**, especialmente con Power BI, SQL, Python, Power Query y DAX.

Me interesa especialmente convertir necesidades de negocio en soluciones claras, mantenibles y útiles: desde dashboards y análisis hasta pipelines de datos y aplicaciones con lógica propia.

## 🚀 Proyectos destacados

### 📊 DataPulse Spain — analítica macroeconómica end-to-end

Proyecto de Data Analytics que compara **España, Portugal, Francia, Italia y Alemania** a partir de datos de la World Bank Indicators API.

Incluye extracción automática, transformación con Pandas, controles de calidad, persistencia en SQLite, consultas SQL, KPIs, tests, CI y un dashboard público desplegado con Streamlit.

`Python` `Pandas` `SQL` `SQLite` `Streamlit` `Data Quality` `GitHub Actions`

🌐 [Abrir dashboard](https://datapulse-spain.streamlit.app/)  
💻 [Ver repositorio](https://github.com/cdeniaca/datapulse-spain)

---

### 🥕 FoodLoop — inventario doméstico local-first

Aplicación web para registrar compras, consumo y stock doméstico mediante un **histórico de movimientos**, en lugar de limitarse a sobrescribir cantidades.

Incluye persistencia con IndexedDB, seguimiento de stock y caducidades, OCR de tickets con Tesseract.js, sugerencias de reposición, exportaciones CSV/XLSX y backups.

`JavaScript` `IndexedDB` `Tesseract.js` `OCR` `Local-first`

🌐 [Abrir FoodLoop](https://www.cristinadeniacarretero.com/foodloop/)  
💻 [Ver código](https://github.com/cdeniaca/cdeniaca.github.io/tree/main/foodloop)

---

### 🇪🇸 Teletrabajo, salarios y gasto en España

Proyecto de análisis sobre población activa, teletrabajo, salarios y gasto por comunidad autónoma en España.

Trabaja con integración de varias fuentes, limpieza de datos, análisis exploratorio y visualización para estudiar diferencias regionales y evolución temporal.

`Python` `Pandas` `Matplotlib` `Seaborn` `EDA`

💻 [Ver repositorio](https://github.com/cdeniaca/Group-7)

---

### 🎾 Helikepadel — web para torneo deportivo

Proyecto web responsive para presentar un torneo de pádel, con información de inscripción, categorías, premios y resultados.

`HTML` `CSS` `Bootstrap` `JavaScript` `Responsive Design`
