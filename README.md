## 🚀 Proyectos destacados

### 🥕 FoodLoop — inventario doméstico local-first

<img align="right" src="https://raw.githubusercontent.com/cdeniaca/cdeniaca.github.io/main/images/FoodLoop_Logo.svg" width="120" alt="FoodLoop">

Aplicación web para registrar compras, consumo y stock doméstico manteniendo un **histórico de movimientos** en lugar de sobrescribir cantidades.

A partir de ese histórico, FoodLoop puede identificar patrones de compra y ayudar a decidir cuándo conviene reponer productos.

**Incluye:**

- persistencia local con **IndexedDB**
- registro de compras, consumo, desperdicio y ajustes
- seguimiento de stock y caducidades
- sugerencias de reposición basadas en hábitos
- OCR de tickets con **Tesseract.js**
- exportación a CSV/XLSX
- copias de seguridad y restauración
- interfaz responsive para móvil y escritorio

`JavaScript` `IndexedDB` `OCR` `Tesseract.js` `Local-first` `CSV/XLSX`
